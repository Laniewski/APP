# Legacy code

Ten katalog zawiera kod poprzedniej wersji aplikacji APPv2.

Kod służy wyłącznie jako referencja podczas budowy nowego GUI i późniejszych sterowników.
Stara aplikacja po reorganizacji nie musi być uruchamialna.

Stare sterowniki będą analizowane pojedynczo podczas wdrażania urządzeń.
Nieusuwane funkcje pozostały celowo, aby zachować pełne źródło referencyjne.
